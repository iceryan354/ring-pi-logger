# Ring PI Logger

Logs perfusion index (PI), SpO2 and pulse from a Wellue/Viatom O2Ring over Bluetooth, in the browser.

Open https://iceryan354.github.io/ring-pi-logger/ in **Bluefy** on iPhone (Safari has no Web Bluetooth), or in Chrome/Edge on a computer.

Readings stay on the device (IndexedDB) and export as CSV. Protocol details from [ecostech/viatom-ble](https://github.com/ecostech/viatom-ble).
